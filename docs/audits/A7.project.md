# A7 overlay — MoMo Kasi

Appended to the shared A7 brief. **A7 is deliberately re-scoped for this project.**

## Why A7 is enabled with no native app

There is no iOS or Android app and there never will be in this build (`docs/00` §7). Normally that
would disable A7. It is enabled because the half of A7 that matters here — **offline behaviour and
platform conventions on a phone** — is a MUST-adjacent feature we demonstrate live, in airplane
mode, in front of judges (`docs/08` §3).

## In scope

**Offline-first PWA (workstream S2):**

- Service worker caches the app shell; the app must open with **zero** network.
- Reads persisted to IndexedDB; losing a data bundle degrades to **read-only**, never to an error
  screen. ICASA out-of-bundle disconnection is abrupt and mid-session (`docs/00` §6a).
- Fare capture queues locally and syncs via Background Sync on reconnect.
- **The queue must be durable and idempotent.** A fare captured offline and synced twice must
  produce one payment. This is the same guarantee as the webhook path, and it is **Critical** if
  broken.
- The offline state must be *visible*. A user must never believe a payment succeeded when it is
  queued. A queued fare says "queued — will settle when you have signal".

**Phone conventions:**

- Safe areas and notches; the bottom sheet must clear the home indicator.
- `viewport-fit`, `100dvh` rather than `100vh` for the chat column.
- Pull-to-refresh must not fight the sheet's drag gesture.
- Keyboard avoidance: the composer must stay visible when the on-screen keyboard opens.
- Installability: manifest, icons, `theme-color`, an install prompt that is not obnoxious.

## Out of scope — report as N/A, not as a gap

- App Store / Play Store readiness, listings, screenshots, privacy nutrition labels.
- Native permissions, push notification entitlements, deep-link association files.
- Platform HIG or Material conformance.
- Native crash reporting or release channels.

Mark these **Not applicable — no native app (`docs/00` §7)**, so the report does not read as if we
failed a check we deliberately never took on.

## The demo dependency

The airplane-mode moment is scripted in `docs/08` §3, minute 3:30. If offline capture is broken,
that is not merely a finding — it removes a scripted beat from the pitch. Grade accordingly and say
so explicitly in the report.
