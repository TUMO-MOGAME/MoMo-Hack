# A2 overlay — MoMo Kasi

Appended to the shared A2 brief.

## What the design reference actually is

`C:/Social-Assembly-Main/apps/web` — a different product by the same author, adopted here as the
**design system**, not as a visual target. So A2's question is sharper than usual:

> Where this build differs from the reference, was that a **decision** or a **drift**?

## Deliberate differences — do not report these

| Difference | Why |
|---|---|
| `brand` is MTN gold, not violet/fuchsia | Different product, different audience. An MTN hackathon entry should read as MTN at a glance. Recorded in `src/design/tokens.ts`. |
| No `sidebar-*` roles | This app has no sidebar. The chat is the spine. |
| No `critical` colour role | We use `warning` and `destructive`; there is no third attention tier. |
| Chat is phone-first, sheet on mobile | The reference is desktop-first. Our users are on phones at a rank (`docs/13` §6). |
| No CopilotKit runtime yet | Starter uses a deterministic mock agent (`STATUS.md` S7a). |

## What is meant to be identical — report any drift

- **Semantic tokens only.** Any raw palette utility (`bg-neutral-900`, `text-slate-700`), hex, or
  inline `oklch()` in a component is a finding. The rule is `bg-primary`, `text-muted-foreground`,
  `border-border` — reference the role, never the value.
- **`src/design/tokens.ts` is the single source of truth.** A colour defined only in
  `globals.css` and not in `tokens.ts` is drift. So is the reverse.
- The **glowing-black dark palette** — pure black ground, `0.08` cards, white foreground, the
  `--glow` shadows.
- **Radius** base `0.625rem`; use `rounded-lg` and friends, never arbitrary values.
- **Motion** durations 150/240/400ms with `cubic-bezier(0.4, 0, 0.2, 1)`.
- **Type**: Geist for UI, Geist Mono for numerics, Playfair Display for the brand moment and large
  amounts. A fourth family is drift.

## The token drift gate

`globals.css` is generated from `tokens.ts`. Confirm the values still agree. The reference project
has a `tokens:check` CI job that regenerates and fails on `git diff --exit-code`; we have adopted
the architecture but **not yet the gate** — flag it if Phase 3 closes without one.

## Not measurable yet

The frontend template Tumo is providing may supersede visual choices here. Until it lands, grade
**structure and system adherence**, not aesthetics. Do not report subjective taste as a finding.
